# Security Policy

## Reporting Security Issues

Do not report security issues through public GitHub issues, discussions, or pull requests.

Report them privately through GitHub's private vulnerability reporting:

[Report a vulnerability](https://github.com/olalie/tapmap/security/advisories/new)

The report is visible only to the maintainer until an advisory is published. A GitHub account is required.

Include:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Potential impact
- Proof of concept if available

## Supported Versions

Security fixes are normally applied only to the latest released version.

## Scope

Examples of security issues:

- Remote code execution
- Privilege escalation
- Unsafe file handling
- Dependency vulnerabilities
- Unexpected exposure of local network information

General bugs, feature requests, and usability issues should be reported through GitHub Issues.

## Disclosure

Please allow reasonable time for investigation before public disclosure.

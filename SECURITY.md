# Security Policy

## Reporting Security Issues

If you believe you have found a security issue in TapMap, do not open a public issue.

Please contact the maintainer directly.

Include:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Potential impact
- Proof of concept if available

## Supported Versions

Security fixes are normally applied only to the latest released version.

## Scope

Examples of security issues:

- Remote code execution
- Privilege escalation
- Unsafe file handling
- Dependency vulnerabilities
- Unexpected exposure of local network information

General bugs, feature requests, and usability issues should be reported through GitHub Issues.

## Disclosure

Please allow reasonable time for investigation before public disclosure.
